🌐 IP 주소 관리 및 변경

보안 정책상 IP 주소는 네트워크 설정에서 직접 변경해야 합니다.

1. 아래 [네트워크 연결 열기] 버튼 클릭
2. 사용 중인 어댑터(이더넷 등) 우클릭 → 속성
3. 인터넷 프로토콜 버전 4 (TCP/IPv4) 더블클릭
4. 지정받은 IP 주소 입력 후 확인
