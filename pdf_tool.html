합칠 파일 목록

우측 상단의 '+ 파일 추가' 버튼을 눌러 파일을 불러오세요.

💡

이용 안내

  • 여러 개의 PDF 파일을 하나의 파일로 연결하여 병합합니다.
  • 목록에 추가된 파일을 마우스로 드래그(끌어놓기)하거나 우측 화살표 버튼을 눌러 문서가 합쳐질 순서를 변경할 수 있습니다.

원본 파일 선택

선택된 파일이 없습니다.

추출할(남길) 페이지 범위

💡

이용 안내

  • 원본 문서에서 필요한 페이지만 골라내어 새로운 PDF 파일로 추출(저장)합니다.
  • 입력 예시: 1-5 (1~5페이지만), 3, 7 (3페이지와 7페이지만), 1-3, 8 (혼합 사용 가능)
  • 입력칸을 비워두면 문서 전체가 선택됩니다.

개별 저장할 파일 선택

선택된 파일이 없습니다.
💡

이용 안내

  • 선택한 PDF의 모든 페이지를 각각 1장짜리 문서로 조각내어 한꺼번에 저장합니다.
  • 실행 버튼을 누른 후, 수많은 파일들이 안전하게 보관될 [폴더]를 하나 지정해 주시면 됩니다.
  • 저장되는 파일명은 원본명_1페이지.pdf, 원본명_2페이지.pdf 형식으로 자동 생성됩니다.

원본 파일 선택

선택된 파일이 없습니다.

삭제할 페이지 범위

💡

이용 안내

  • 원본 문서에서 불필요한 페이지만 쏙 빼고(삭제하고) 나머지 페이지들로 PDF를 재구성합니다.
  • 입력 예시: 2 (2페이지만 삭제), 4-6 (4~6페이지 삭제)
  • 실수로 들어간 백지나 불필요한 표지를 제거할 때 매우 유용합니다.

회전할 파일 선택

선택된 파일이 없습니다.

회전할 페이지 범위

회전 각도 선택

💡

이용 안내

  • 스캔 방향이 거꾸로 되거나 가로/세로가 잘못 섞인 문서의 방향을 바로잡아 줍니다.
  • 범위 칸을 비워두거나 all을 입력하면 문서 전체가 일괄 회전됩니다.
  • 특정 페이지만 거꾸로 스캔된 경우 2, 4 처럼 해당 페이지만 지정하여 회전시킬 수 있습니다.

대상 문서 (도장 찍힐 파일)

선택된 파일이 없습니다.

워터마크용 PDF (도장/글귀 파일)

선택된 파일이 없습니다.
💡

이용 안내

  • 대상 문서의 모든 페이지 위에 투명한 셀로판지처럼 도장이나 로고를 겹쳐서 찍어줍니다. (대외비, 초안 표기 등)
  • 워터마크용 파일은 반드시 1페이지짜리 PDF 파일이어야 합니다.
  • 그림판이나 한글에서 글귀/도장을 만든 후 'PDF로 저장'한 파일을 사용하시면 편리합니다.

텍스트를 추출할 파일 선택

선택된 파일이 없습니다.
💡

이용 안내

  • PDF 문서 내부에 포함된 텍스트(글자)만 쫙 뽑아내어 메모장(.txt) 파일로 저장해 줍니다.
  • 다른 기관에서 온 복사 불가능한 PDF 공문 등의 내용을 참고할 때 유용합니다.
  • 주의: 마우스로 글자가 드래그(선택)되는 정상적인 PDF만 가능하며, 이미지(사진) 형태로 스캔된 문서의 글자는 추출할 수 없습니다.

압축할 파일 선택

선택된 파일이 없습니다.

압축 기능 이용 안내

  • 현재 펜통에서 제공하는 압축은 화질 손상이 전혀 없는 '기본 무손실 압축(메타데이터 및 구조 정리)'입니다.
  • 따라서 스캔본이나 고화질 이미지가 포함된 문서의 경우 용량 감소 효과가 거의 없을 수 있습니다.
  • 강력한 고비율 압축이 필요하신 경우, 당분간 다른 전문 압축 도구(웹사이트 등)를 활용해 주시기를 권장합니다.
  • 🚀 차후 이미지 압축에 특화된 강력한 전용 프로그램 'PenPDF'를 별도로 개발하여 제공할 계획입니다!

작업 선택

💡

이용 안내

  • 비밀번호 설정: 민감한 개인정보 문서 등에 새로운 열기 암호를 걸어 안전하게 보호합니다.
  • 비밀번호 해제: 암호가 걸려있는 문서의 기존 암호를 입력하여, 영구적으로 암호가 풀린 새로운 파일을 만듭니다. (자주 여는 문서에 매번 암호를 치기 번거로울 때 유용합니다.)
