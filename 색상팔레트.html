💡 색상 팔레트 활용 방법

펜통 색상 팔레트는 교재, 가정통신문, PPT를 만들 때 전문가처럼 세련된 색상을 클릭 한 번에 복사하여 사용할 수 있도록 돕는 도구입니다.

📊 파워포인트(PPT) 적용 예시

  1. 펜통 팔레트에서 마음에 드는 색상을 클릭하여 선택합니다.
  2. 좌측 패널에서 파란색 [복사하기] 버튼을 누릅니다.
    (이때 클립보드에 코드가 저장되며 최근 사용 목록에도 추가됩니다. 예: #FFB3BA)
  3. 파워포인트에서 색상을 바꿀 도형이나 글자를 선택합니다.
  4. 상단 메뉴에서 [도형 채우기] 또는 [글꼴 색] 버튼을 누르고 맨 아래의 [다른 색(M)...]을 클릭합니다.
  5. 색상 팝업창 상단의 [사용자 지정] 탭을 누릅니다.
  6. 하단의 'Hex(16진수)' 입력칸에 복사해 둔 코드를 붙여넣기(Ctrl+V) 한 뒤 [확인]을 누르면 끝!

📝 한글(hwp) / 기타 프로그램

  • 한글, 미리캔버스, 웹 디자인 도구 등 대부분의 프로그램도 '16진수' 또는 'HEX 코드' 입력란에 코드를 붙여넣어 사용합니다.
  • 프로그램에 코드를 입력하는 곳이 없다면, 펜통 좌측 패널에 표시된 R, G, B 숫자 세 개를 확인하여 그대로 입력해 주세요.
