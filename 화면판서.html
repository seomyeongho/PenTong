프로젝터 화면 판서

현재 화면 위에 투명한 도화지를 펼쳐, 어떤 프로그램(PPT, 웹 브라우저, 영상 등) 위에서도
자유롭게 필기하고 화면을 제어할 수 있는 강의 및 발표용 판서 도구입니다.

패널 띄울 위치
💡 판서 패널 이용 방법 (클릭하여 펼치기)
  • 화면 상단 정중앙에 나타난 작은 패널의 📷 (카메라 아이콘)을 누르거나 키보드 F1 키를 누르면 즉시 화면이 정지되고 필기가 가능합니다.
  • 판서가 끝나면 다시 ⏹️ (정지 아이콘)을 눌러 원래 PC 화면으로 돌아갑니다.
  • 패널 좌측 끝의 ⠿ 모양을 잡고 드래그하면 화면에서 방해되지 않는 곳으로 치워둘 수 있습니다.
  • 완전히 사용을 마치셨다면 패널 우측 끝의 ❌ 를 눌러 종료하세요.

📖 화면 판서 상세 도움말

🖱️ 마우스 & 터치 조작

  • 좌클릭 드래그: 펜 그리기 및 도형 생성
  • 우클릭 드래그: 화면 이동 (패닝)
  • 마우스 휠 굴리기: 화면 확대 / 축소 (최소 100% 원본 크기 유지)
  • Shift + 좌클릭 드래그: 수평, 수직, 대각선(45도) 반듯한 직선 긋기
  • (전자칠판) ✌️ 두 손가락 제스처: 스마트폰처럼 벌려서 확대, 오므려서 축소, 그대로 화면 이동 가능
  • (타이머 모드 시) 휠 굴리기: 1분 단위로 시간 증가/감소

⌨️ 단축키 안내

  • F1 : 판서 시작 (화면을 멈추고 필기 모드 진입)
  • ESC : 판서 종료 (타이머 실행 중일 때는 타이머만 종료)
  • Ctrl + Z : 한 단계 실행 취소 (되돌리기)
  • C : 화면 전체 지우기 (Clear)
  • F : 마법펜(Fade) 켜기/끄기 (그은 선이 3초 뒤 서서히 사라짐)
  • T : 타이머 모드 켜기/끄기 (기본 10분)
  • M : 마우스 커서 이펙트(노란 반투명 원) 켜기/끄기

🎨 도구 및 색상 단축키

  • P : 일반 펜 모드
  • H : 반투명 형광펜 모드
  • R / B / G / Y : 각각 빨강, 파랑, 초록, 노랑 색상 변경
