파일 불러오기

PDF / 이미지 삽입

수업용 PDF 교재나 이미지(JPG, PNG)를 칠판으로 바로 불러옵니다. PDF 문서는 고해상도(3배율)로 변환되어 확대해도 글씨가 깨지지 않으며, 여러 장의 PDF를 불러올 경우 자동으로 칠판 페이지가 추가되어 순서대로 삽입됩니다.

프로젝트 열기

이전에 작업 후 저장해 둔 .json 프로젝트 파일을 불러옵니다. 기존 칠판에 내용이 있을 경우, 1) 현재 페이지 덮어쓰기, 2) 기존 내용은 유지하고 추가로 불러오기 중 원하는 방식을 선택할 수 있어 유연한 수업 준비가 가능합니다.

저장 및 내보내기

프로젝트 저장 (.json)

현재까지 작업한 칠판의 모든 페이지, 필기, 도형, 배경 상태를 언제든 다시 수정 가능한 원본 데이터 형태로 컴퓨터에 저장합니다. 다음 시간이나 내년 수업 때 그대로 이어서 작업할 수 있는 가장 완벽한 백업 방식입니다.

이미지로 캡처 (PNG)

현재 화면에 보이는 칠판(1페이지 분량)을 배경을 포함한 고화질 이미지(PNG) 파일로 즉시 저장합니다. 필기 완성본을 학생들에게 메신저로 간편하게 공유할 때 좋습니다.

PDF로 내보내기

현재 칠판 화면을 PDF 문서 형식으로 구워냅니다. 판서 내용을 모아서 인쇄물로 배포할 때 최적화된 형식입니다.

배경 테마 설정

  • 영어 4선지: 실제 알파벳 공책 비율에 맞춰 세 번째 줄이 빨간색으로 강조된 초/중등 영어 필기용 특화 테마입니다.
  • 오선지: 음악 수업을 위한 5줄 악보 배경입니다.
  • 모눈 및 줄노트: 글씨나 수식을 반듯하게 맞추어 쓸 수 있는 가이드라인을 제공합니다.
  • 칠판/흑판: 눈이 편안한 짙은 녹색 칠판이나 검정 흑판 색상으로 전환할 수 있습니다.

수업 교구 및 위젯

  • 추첨 룰렛
    하단 텍스트 입력창에 쉼표(,)를 기준으로 조 이름이나 학생 번호(예: 1조, 2조, 3조...)를 입력하세요. [돌리기!] 버튼을 누르면 부드러운 애니메이션과 함께 랜덤 추첨이 진행됩니다.
  • 위젯 크기 자유 조절
    주사위, 룰렛, 타이머 위젯의 오른쪽 아래 모서리(회색 빗금 친 부분)를 마우스로 잡고 당기면 윈도우 창을 조절하듯 크기를 자유롭게 확대하거나 축소할 수 있습니다.
  • 정답 가리개 (부분)
    교구함에서 선택 후 화면에 드래그하여 불투명한 회색 가림막을 만듭니다. 생성된 가림막을 더블 클릭하면 반투명하게 투과되어 숨겨진 정답을 보여줄 수 있습니다.
  • 전체 화면 가림막
    툴바의 가림막 버튼을 누르면 화면 전체가 어둡게 가려집니다. 가림막의 상, 하, 좌, 우 및 모서리에 있는 바(Bar)를 마우스로 잡고 드래그하면 원하는 방향으로 칠판을 서서히 열어 보여줄 수 있습니다.
  • 타이머
    +1분, +5분 버튼으로 시간을 설정하고 재생 버튼을 누릅니다. 시간이 00:00이 되면 "띠-딕" 하는 알림음과 함께 종료 팝업이 뜹니다. 창 우측 상단의 [X]를 누르면 타이머가 즉시 초기화되며 닫힙니다.
  • 부분 돋보기
    화면의 특정 부분을 동그랗게 확대해 보여줍니다. 교재의 작은 글씨나 지도를 설명할 때 유용하며, 테두리를 잡고 자유롭게 이동시킬 수 있습니다.

유용한 키보드 단축키

[ V / ESC ] 선택 모드
[ P ] 일반 펜
[ H ] 형광펜
[ L ] 레이저 포인터
[ E ] 지우개
[ M ] 화면 잡고 이동
[ T ] 텍스트 박스
[ S ] 스티커 메모
[ Del / Back ] 개체 삭제
[ Ctrl + Z / Y ] 실행 취소 / 다시 실행
[ Ctrl + C / V ] 복사 / 붙여넣기
[ Ctrl + D / G ] 복제 / 그룹화

숨겨진 꿀팁

  • 자석 기능 (그리드 스냅) : 켜두면 도형이나 스티커 메모를 이동하거나 크기를 조절할 때 모눈(격자) 칸에 자석처럼 딱딱 맞춰서 반듯하게 정렬됩니다.
  • 마우스 우클릭 (컨텍스트 메뉴) : 선택한 객체 위에서 마우스 우클릭 시 레이어 순서 변경, 잠금, 그룹화, 복사 등 필수 편집 메뉴가 나타납니다.
  • 칭찬 스탬프 : 스탬프를 칠판에 한 번 찍고 나면, 바로 크기나 위치를 이동시킬 수 있도록 [선택 모드]로 자동 전환됩니다.
  • 스포트라이트 단축 해제 : 스포트라이트를 켠 상태에서 마우스 휠을 굴려 반경을 조절할 수 있으며, 키보드 [ESC] 키를 누르면 마우스를 메뉴까지 옮길 필요 없이 즉시 해제됩니다.
