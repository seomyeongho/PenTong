    선생님, 환영합니다! PenBook은 코딩을 몰라도, AI가 만들어준 코드를 복사해서 붙여넣기만 하면 나만의 디지털 교과서, 학습지, 시뮬레이션 프로그램이 완성되는 마법의 저작 도구입니다.

    1️⃣ 목차(TOC) 구성 및 관리하기

    좌측의 목차 패널에서 각 항목에 마우스를 올리면 나타나는 우측 점 세 개(⋮) 아이콘을 클릭하거나, 항목 위에서 마우스 우클릭을 해보세요. [새 페이지 추가], [제목 변경], [삭제] 등의 관리 메뉴가 나타납니다.

    • 순서 및 소속 바꾸기: 목차 항목을 마우스로 꾹 누른 채 위아래로 끌어다 놓으면(드래그 앤 드롭) 자유롭게 순서를 바꾸거나 다른 폴더 속으로 집어넣을 수 있습니다.
    • 키보드 단축 이동: 키보드 방향키(↑, ↓)를 누르면 목차를 매우 빠르게 넘겨볼 수 있습니다.

    2️⃣ 중앙 에디터 & 우측 뷰어

    중앙의 검은 화면은 AI가 짜준 코드를 넣는 에디터(도화지)입니다. AI의 코드를 복사한 뒤 에디터 상단의 [📋 코드 교체] 버튼을 누르면 단 1초 만에 내용이 덮어써집니다.

    • A4 모드: 학습지나 읽기 자료 등 인쇄가 필요할 때 씁니다. (실제 프린트 비율)
    • 폭맞춤 모드: 퀴즈, 타이머, 과학 시뮬레이션 등 빈틈없이 화면 전체를 써야 할 때 유용합니다.
    • 제목 표시: 우측 상단의 [제목 표시 ON/OFF] 버튼을 눌러 결과창 최상단에 현재 페이지의 제목을 띄우거나 숨길 수 있습니다.

    3️⃣ 알아두면 유용한 꿀팁 단축키

    • [Shift + Ctrl + F] : 단어 찾기 및 모두 바꾸기 (오타를 한 번에 수정할 때 필수!)
    • [Ctrl + 휠 굴리기] : 결과물 화면만 부드럽게 확대/축소 (글씨가 작을 때 사용)
    • 결과 화면 아래에 숨어있는 [이전/다음 플로팅 버튼]의 가운데(⋮)를 마우스로 잡으면 화면의 원하는 위치로 자유롭게 던져둘 수 있습니다!

    PenBook의 진짜 매력은 ChatGPT, Claude, Gemini 같은 AI 챗봇과 대화하며 나만의 수업 도구를 만들어가는 데 있습니다. 어려운 컴퓨터 용어는 몰라도 괜찮습니다. AI에게 대화하듯 편하게 요청하세요!

    💡 처음 요청할 때 기억할 딱 한 가지

    AI에게 어떤 수업 자료를 만들어 달라고 말하든, 이야기 끝에 이 한 줄만 똑같이 붙여주세요. 그래야 PenBook에서 1초 만에 바로 실행됩니다.

    "~를 만들어줘. 하나의 html 코드로 만들어줘."

    🔥 원하는 결과가 안 나왔을 때? "계속 고쳐 쓰는 연속 수정 기술"

    AI가 처음에 만들어 준 결과물이 마음에 쏙 들지 않더라도 실망하지 마세요. 그 상태에서 마치 사람에게 피드백을 주듯 이어서 추가 지시를 내리면 원하는 모습으로 계속 업그레이드됩니다.

    🎨 1. 화면이나 디자인이 아쉬울 때

    글씨가 너무 작거나, 분위기가 수업과 맞지 않는다면 구체적으로 요구하세요.

    • "교실 맨 뒷자리에서도 보이게 숫자랑 버튼 크기를 엄청 크게 키워줘."
    • "초등학생들이 좋아할 만한 귀엽고 아기자기한 색감으로 디자인을 바꿔줘."

    ⚙️ 2. 기능이 빠졌거나 추가하고 싶을 때

    동작을 제어하고 싶거나 새로운 규칙을 심고 싶다면 그대로 말하세요.

    • "작동이 안 돼. 시작 버튼을 누르면 그때부터 움직이도록 고쳐줘."
    • "원판이 멈추었을 때 화면 전체에 빵파레가 터지는 효과를 추가해줘."

    📄 3. 코드가 끊기거나 나눠서 줄 때 (대처법 2가지)

    답변이 길어지면 AI가 중간에 코드를 자르거나 쪼개 줄 수 있습니다. 상황에 맞게 골라 쓰세요.

    • 방법 A (전체 다시 받기): "코드가 중간에 끊겼어. 끊긴 부분부터 이어서 전체 코드를 처음부터 끝까지 생략하지 말고 한 번에 완성해서 출력해줘."라고 지시해 하나의 깨끗한 완성본을 다시 받습니다.
    • 방법 B (수정 위치만 안내받기): 분량이 너무 길어 전체 코드를 다시 뽑는 속도가 답답하다면, "방금 코드에서 어느 부분을 어떻게 수정해야 하는지, 수정할 위치와 바뀔 코드 조각만 정확히 알려줘."라고 요청합니다. 이후 그 부분만 복사해 에디터에서 직접 교체하면 응답 시간을 획기적으로 단축할 수 있습니다.
    💥 초강력 꿀팁 (수정하다가 오류가 나서 작동이 멈췄을 때):
    가이드대로 코드를 직접 조각조각 수정하다가 꼬여버려서 우측 화면이 하얗게 멈췄나요? 걱정하지 마세요! 현재 PenBook 에디터 창에 들어있는 소스코드 전체를 그대로 복사해서 AI에게 다시 던져주세요. 그리고 "이 소스코드에서 오류가 나는데, 정상적으로 작동하게 완벽히 고쳐서 다시 하나의 html 코드로 짜줘."라고 명령하면 AI가 귀신같이 오류를 찾아 수리해 줍니다!

    아래의 명령어 예시를 마우스로 드래그하여 복사한 뒤, AI에게 그대로 붙여넣어 보세요. 선생님의 아이디어를 덧붙여 대화를 이어 나가면 더 완벽해집니다!

    🔭 예시 1. [과학] 움직이는 우주 및 태양계 시뮬레이션

    교과서 속 평면 그림 대신, 학생들이 직접 속도를 만지며 노는 입체적인 자료를 요청합니다.

    초등학교 과학 '태양계와 별' 수업에 쓸 화려하고 입체적인 웹 시뮬레이션을 만들어줘. 화면 중앙에 태양이 있고, 행성들이 궤도를 따라 실제로 움직이는 모습을 멋지게 구현해줘. 학생들이 행성들의 빠르기를 직접 제어할 수 있게 조절 바를 넣어주고, 각 행성을 마우스로 클릭하면 행성의 특징이 설명창으로 예쁘게 나타나게 해줘. 하나의 html 코드로 만들어줘.

    🎲 예시 2. [창체/국어] 교실용 발표자 뽑기 룰렛

    아이들의 시선을 단번에 사로잡는 모둠/개인 발표용 게임 도구를 기획합니다.

    교실 TV에 띄워놓고 사용할 발표자 뽑기 원판 룰렛 게임을 만들어줘. 선생님이 학생 이름을 마음대로 입력할 수 있는 칸이 있고, 이름을 넣으면 원판 조각이 자동으로 균등하게 나뉘어야 해. '돌리기' 버튼을 누르면 룰렛이 빙글빙글 돌다가 멈추면서 당첨자가 정해지게 해주고, 당첨이 되면 화면 가득 축하 효과가 나타나게 해줘. 아이들이 좋아할 만한 아주 예쁘고 신나는 디자인으로 꾸며줘. 하나의 html 코드로 만들어줘.

    🔭 예시 3. [과학/환경] 물의 순환 반응형 학습 교재 (핵심 정리 + 개념 퀴즈)

    교과서 속 평면적인 물의 순환 개념을 학생들이 인터랙티브하게 학습할 수 있는 교재를 만듭니다.

    초등학교 과학 '물의 여행(물의 순환)' 단원을 스스로 공부할 수 있는 반응형 디지털 학습 교재를 만들어줘. 화면 상단에는 물의 순환 과정(증발, 응결, 강수, 수집)을 학생들이 이해하기 쉽게 핵심 개념을 정리하여 가독성 좋게 배치해줘. 화면 하단에는 오늘 배운 내용을 스스로 점검해 볼 수 있도록 3문항의 객관식 퀴즈판을 만들어줘. 학생들이 정답 버튼을 누르면 즉시 정답 여부를 알려주고, 해설 상자가 아래에 나타나게 해줘. 선생님과 학생들이 오랫동안 화면을 봐도 눈이 피로하지 않게 정돈되고 세련된 디자인으로 꾸며줘. 하나의 html 코드로 만들어줘.

    AI가 만들어준 웹 게임이나 실험 시뮬레이션 교보재 중에서 "마우스 클릭 위치가 자꾸 엉뚱한 곳을 짚는다"고 느껴질 때가 있습니다. 이 현상의 정확한 원인과 완벽한 해결 방법을 안내해 드립니다.

    ❓ 오차가 발생하는 원인

    AI는 보통 게임판이 화면 맨 왼쪽 위 구석에 빈틈없이 딱 붙어있을 것이라 가정하고 마우스 위치를 계산합니다. 하지만 PenBook에서 [A4 모드]를 켜면 문서 양식처럼 상하좌우에 하얀 여백이 생기며 게임판을 안쪽으로 밀어내게 되고, 결국 눈에 보이는 포인터 위치와 게임이 인식하는 좌표 사이에 '밀려난 거리만큼' 오차가 발생하게 됩니다.

    💡 가장 완벽한 해결 방법 (AI에게 지시하기)

    이 문제는 소스코드를 수정할 필요 없이, AI에게 코드를 처음 요청하거나 수정해 달라고 대화할 때 아래 문장을 복사해서 그대로 명령문 끝에 붙여주면 완전히 해결됩니다.

    마우스 클릭 위치를 계산할 때, 단순히 화면 전체 기준(clientX)으로 하지 말고 반드시 캔버스 자체의 상대 위치(getBoundingClientRect)를 기준으로 계산해 줘. 상하좌우에 여백이 추가되어 게임판이 밀려나더라도, 마우스 클릭 좌표가 절대 어긋나지 않도록 완벽하게 보정된 코드로 짜줘.

    🛠️ 지금 당장 화면에서 해결하는 임시 대처법

    이미 만들어진 자료에서 당장 클릭 오차를 없애고 테스트하고 싶다면, 툴바 버튼을 조작해 게임판을 화면 구석에 강제로 밀착시켜 주면 됩니다.

    • [폭맞춤] 모드 선택: 상단 툴바에서 [A4] 대신 [폭맞춤]을 눌러 주변의 모든 여백을 0으로 만듭니다.
    • 화면 배율 100% 맞추기: 오른쪽 위의 화면 배율 조절기가 100%로 되어 있는지 확인합니다. (배율이 임의로 확대되거나 축소되어도 좌표가 깨질 수 있습니다.)
