# PenTong (펜통) - 교무·행정 업무 통합 지원 프로그램

학교 및 교육청 현장 교직원들의 원활한 업무 처리를 위해 다양한 편의 기능(전자칠판, 타이머, 데이터 정제, 엑셀/PDF 분할 및 취합 등)을 하나로 모아 제공하는 통합 지원 프로그램입니다. 

복잡한 설치 과정 없이 단독 실행 파일(EXE) 하나로 가볍고 빠르게 구동되어 누구나 쉽게 사용할 수 있습니다. 교육 현장의 업무 효율화를 돕고 오픈소스 생태계에 기여하기 위해 원본 소스 코드를 공개합니다.

* **개발**: 부산광역시교육청 AI·데이터연구팀
* **배포 형태**: 무설치 단독 실행 파일 (Windows EXE)
* **주요 기능**:
  - 교무/수업 지원 (전자칠판, 화면 판서, 모둠 활동, 대진표 등)
  - 데이터 분석 및 정제 (중복 확인, 전화/주소 정제, 주민번호 검증 등)
  - 문서 취합 및 분할 (한글/엑셀 취합, 다중 PDF 병합 등)
  - 기타 시스템 도구 및 타이머
