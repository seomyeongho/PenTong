    엑셀 파일 취합기 사용 방법

    💡 여러 엑셀 파일의 특정 시트 데이터를 모아 하나의 엑셀 문서로 세로(위아래)로 길게 이어 붙이는 기능입니다. 양식이 동일한 자료를 모을 때 유용합니다.

    1. 파일 추가 및 순서 변경

    • 우측 상단의 [파일 추가] 버튼을 눌러 엑셀 파일을 불러옵니다.
    • 목록에 추가된 파일의 이름 영역을 마우스로 잡고 위아래로 드래그하면 취합되는 순서를 바꿀 수 있습니다.

    2. 취합할 시트 선택 (개별/일괄)

    • 개별 선택: 목록 우측의 드롭다운 목록에서 각 파일마다 원하는 시트를 고를 수 있습니다.
    • 일괄 지정: 상단 컨트롤 바의 [📌 시트 일괄 지정]에서 시트를 선택하면, 100개의 파일이라도 같은 이름의 시트를 한 번에 찾아 선택합니다.
    • 해당 시트가 없는 파일은 빨간색 경고가 뜨며 안전하게 취합에서 자동으로 제외됩니다. 수동으로 다른 시트를 골라 다시 포함시킬 수도 있습니다.

    3. 미리보기 및 취합 실행

    • 파일 목록 우측의 [파일 열기 버튼(돋보기 모양)]을 누르면, 엑셀 프로그램이 실행되어 해당 파일의 내용을 미리 확인할 수 있습니다.
    • 설정이 끝난 뒤 우측 상단의 [취합 시작] 버튼을 누르면, 백그라운드에서 데이터를 모아 새로운 엑셀 창에 뿌려줍니다. (결과는 자동 저장되지 않으므로 확인 후 직접 저장해 주세요.)
