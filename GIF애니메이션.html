프로그램 사용법

🎨 기본 편집 도구

  • [V] 선택: 객체 이동, 크기 조절, 회전
  • [W] 마법봉: 클릭 시 배경색 투명화
  • [E] 지우개: 이미지의 특정 부분 지우기
  • [P] 선 그리기: 새로운 독립 레이어에 선 그리기
  • [T] 텍스트: 캔버스 클릭 시 글자 삽입

⌨️ 시스템 단축키

  • Ctrl + C: 선택한 객체 복사
  • Ctrl + V: 객체 또는 외부 이미지 붙여넣기
  • Ctrl + Z: 실행 취소
  • Ctrl + Y: 다시 실행
  • Delete: 선택한 객체 삭제

좌측 패널 (속성 및 설정)

  • 객체 속성: 선택한 객체의 레이어 순서(Z-Order), 좌우 반전, 필터(흑백, 블러 등), 글자 색상을 변경합니다.
  • GIF 공통 설정: 최종 저장될 캔버스의 크기, 전체 반복 횟수, 되감기(왕복) 모드, 기본 지연시간(재생 속도)을 일괄 적용합니다.

우측 패널 (타임라인)

  • 애니메이션 프레임: 순서대로 재생될 각 장면들을 관리합니다. 드래그하여 순서를 바꾸거나, 이전 프레임 보기를 켤 수 있습니다.
  • 공통 프레임: 모든 프레임에 동일하게 나타날 '배경'이나 '전경(워터마크 등)'을 등록하는 공간입니다.

중앙 캔버스 (편집기)

작업 공간을 줌(Zoom)하거나, 프레임 밖 영역으로 넘어가며 자유롭게 선을 그릴 수 있습니다. 상단 재생 버튼을 눌러 미리보기가 가능합니다.

GIF 열기 (프레임 추출)

기존에 만들어진 움직이는 GIF 파일을 불러옵니다. 단순히 사진으로 넣는 것이 아니라, GIF의 모든 장면을 낱장 프레임으로 분해하여 타임라인에 나열하므로 완벽한 재편집이 가능합니다. (초기화 후 열기 / 이어서 붙이기 지원)

프로젝트 저장 / 열기

현재까지 작업한 모든 레이어와 객체 정보, 타임라인 상태를 그대로 보존하여 전용 파일로 저장합니다. 나중에 다시 불러와서 글자를 수정하거나 사진을 옮길 수 있습니다.

GIF 내보내기

모든 편집을 마치고, 실제로 움직이는 표준 GIF 이미지 파일로 렌더링하여 저장합니다. 웹사이트나 메신저에 바로 올릴 수 있는 결과물이 만들어집니다.
